# Fixed HTML Cover-Letter Template

All cover letters use the internal `letter-modern-fixed-v1` HTML template and Puppeteer.

**Output files:** `cover_letters/cover_<company>_<role>.html` and `cover_letters/cover_<company>_<role>.pdf`

The fixed template renders a semantic letter with a salutation, paragraphs, structured bullets, closing, and escaped contact details. The target is one A4 page and 250-300 words; page-count overruns are warnings requiring content edits.
